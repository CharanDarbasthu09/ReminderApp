# Reminder App ⏰

A modern React Native & Expo mobile application featuring Google Stitch (Material 3) design system, offline alarms & notifications, automated activity logging, and LinkedIn-style mind games.

## Features
- 🔔 **Offline System Alarms & Notifications**
- 🎨 **Google Stitch (Material 3) Theme**
- 📱 **System / Dark / Light Mode Switcher**
- 🧠 **LinkedIn Pinpoint & Memory Matrix Mind Games**
- 📜 **Quote of the Day Ticker (Free Web API)**
- 📝 **Notes & Global Category Styles**

## Getting Started
```bash
npm install
npx expo start --tunnel
```
